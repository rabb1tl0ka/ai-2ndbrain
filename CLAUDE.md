## Daily Notes Structure

Each day creates both a markdown file and a directory:
- **`daily/YYYY-MM-DD.md`** — Summary and index of the day's work
- **`daily/YYYY-MM-DD/`** — Detailed research, extensive notes, work products from that day

Link from the daily markdown to files in the directory so the daily file stays an index. Clean up or archive the directory later if its contents aren't worth keeping.
